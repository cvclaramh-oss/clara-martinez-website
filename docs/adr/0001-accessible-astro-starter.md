# 0001 — Usar Accessible Astro Starter como base

- **Fecha:** 2026-09-09
- **Estado:** Vigente

## Contexto

Necesitábamos un punto de partida sólido con accesibilidad, SEO y performance resueltos. La alternativa era construir desde cero, pero implicaba semanas de configuración y riesgo de omitir detalles críticos.

## Decisión

Usar accessible-astro-starter y personalizar encima con el diseño Radical Clarity.

## Alternativas

- **Construir desde cero:** Control total, pero semanas de configuración de accesibilidad, SEO, sitemap, view transitions y estructura de proyecto. Riesgo de omitir detalles críticos de WCAG.
