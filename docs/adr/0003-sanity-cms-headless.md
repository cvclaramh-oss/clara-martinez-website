# 0003 — Sanity como CMS headless

- **Fecha:** 2026-09-09
- **Estado:** Vigente

## Contexto

La clienta necesita añadir y editar proyectos sin tocar código. No tiene conocimientos técnicos.

## Decisión

Sanity como CMS headless para contenido. Cloudflare Pages para hosting. Web3Forms para formulario de contacto.

## Alternativas

- **Strapi:** CMS headless open source. Más control, pero requiere servidor propio y más mantenimiento.
- **Contentful:** CMS headless comercial. Buena documentación, pero coste creciente con el uso.
- **Markdown directo:** Sin CMS, contenido en archivos .md. Más simple, pero la clienta no puede editar sin conocimientos técnicos.
